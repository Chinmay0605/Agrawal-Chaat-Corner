# Agrawal Chaat Corner

Official website for **Agrawal Chaat Corner**, Indore.

> बुजुर्गों की देन

A traditional food showcase website featuring our street-food favourites and homemade specialties.

## Features

- Traditional Indian street-food menu
- Homemade products collection
- Our Story section
- Location and opening hours
- Direct phone call links
- Google Maps location
- Responsive design for desktop and mobile
- Premium traditional Indian-inspired UI
